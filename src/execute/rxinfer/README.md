# RxInfer.jl Execution Module

This submodule handles execution of RxInfer.jl simulations generated by the render stage.

## Overview

This module executes RxInfer.jl simulation scripts, manages Julia environment setup, captures results, and provides comprehensive reporting on genuine `@model` + `infer()` variational message-passing execution.

## Module Structure

```
src/execute/rxinfer/
├── __init__.py                 # Module initialization
├── README.md                   # This documentation
├── AGENTS.md                   # Detailed agent scaffolding
├── rxinfer_runner.py          # Main execution runner (passes --project=<env>)
├── rxinfer_results.py         # Result parsing / reporting helpers
├── rxinfer_runner.jl          # Julia runner for TOML configs
├── setup_environment.jl       # Pkg.activate() + Pkg.instantiate() (no runtime Pkg.add)
├── Project.toml               # Committed deps (RxInfer 5.5.0)
├── Manifest.toml              # Committed lockfile
└── src/GnnRxInferModels.jl    # Julia package holding the shared @model definitions
```

## Core Components

### RxInfer Runner (`rxinfer_runner.py`)

**Purpose**: Execute RxInfer.jl simulation scripts

**Key Functions** (re-exported from `execute.rxinfer`):
- `run_rxinfer_scripts(rendered_simulators_dir, execution_output_dir=None, recursive_search=True, verbose=False) -> bool` - Execute all RxInfer scripts under `<rendered_simulators_dir>/rxinfer`
- `find_rxinfer_scripts(base_dir, recursive=True) -> List[Path]` - Discover `*_rxinfer.jl` scripts
- `execute_rxinfer_script(script_path, verbose=False, output_dir=None, timeout=300) -> bool` - Run one script under the committed project
- `is_julia_available() -> bool` - Julia on `PATH` check

### Result Helpers (`rxinfer_results.py`)

- `parse_rxinfer_output()`, `collect_rxinfer_results()` - Load `simulation_results.json` files
- `extract_convergence_metrics()`, `summarize_posteriors()` - Free energy / posterior summaries
- `format_rxinfer_report()` - Markdown report over collected results

### Julia Runner (`rxinfer_runner.jl`)

**Purpose**: Julia-side execution logic

**Features**:
- RxInfer module loading
- Reactive constraint setup
- Inference execution
- Result collection

## Output

Execution produces:
- `summaries/execution_summary.json` - Execution summary (from Step 12)
- `simulation_results.json` - Detailed per-run results (schema `rxinfer_simulation_v1`)
- `execution_logs/` - Per-script logs
- `simulation_data/` - Raw simulation outputs

## Dependencies

- `julia` - Julia runtime (required)
- `RxInfer.jl` - Julia package (5.5.0, pinned by committed `Project.toml` + `Manifest.toml` in this directory)
- Plots/JSON/Distributions/StatsBase etc. — all pinned in the committed Manifest

## Environment Setup

Julia environment is reproducible and committed:
- `Project.toml` + `Manifest.toml` pin RxInfer 5.5.0 and all dependencies
- `setup_environment.jl` runs `Pkg.activate()` + `Pkg.instantiate()` — **no runtime `Pkg.add`**
- The runner invokes `julia --startup-file=no --project=src/execute/rxinfer <script>`
- Each run records `Random.seed!(seed)` and the script SHA256 in `runtime_metadata` for byte-identical, reproducible execution
