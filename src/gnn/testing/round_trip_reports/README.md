# Round-Trip Test Reports

Archived results from GNN parse→serialize→re-parse round-trip fidelity tests.

## Contents

- `round_trip_report_*.md` — Human-readable reports showing field-level comparison
- `round_trip_results_*.json` — Machine-readable pass/fail results per format

## Purpose

Validates that the parsers in the default round-trip list (**21** formats) produce identical output when content is serialized
and re-parsed, ensuring lossless format conversion across that list (PNML/EBNF are outside it; see [`../README.md`](../README.md)).

## Usage

Reports are auto-generated by `gnn/testing/test_round_trip.py` and stored here
for regression tracking. Each report includes per-field comparison data and a
summary pass/fail verdict per parser-serializer pair.
