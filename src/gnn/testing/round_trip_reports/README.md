# Round-Trip Test Reports

Archived results from GNN parse→serialize→re-parse round-trip fidelity tests.

## Contents

- `round_trip_report_*.md` — Human-readable reports showing field-level comparison
- `round_trip_results_*.json` — Machine-readable pass/fail results per format

## Oracle Contract

Validates that the parsers/serializers for the **21** formats listed in
`FORMAT_TEST_CONFIG["test_formats"]` (with `test_all_formats: False` in
`src/gnn/testing/round_trip_config.py`) round-trip losslessly: the reference
model is serialized to the target format, written to a temporary file, parsed
back, and compared for **semantic equivalence** — original vs parsed-back
model checksums plus field-level difference recording (`_test_round_trip` in
`round_trip_tester.py`). Formats without an available parser are recorded as
pass-with-warning rather than asserted.

**Outside the list:** `pnml` is disabled in the config (parse-focused);
`ebnf` shares the BNF / `GrammarSerializer` machinery — see
[`../README.md`](../README.md).

## Report Production

Reports are produced **on demand**, not by CI: instantiate
`GNNRoundTripTester` from `round_trip_tester.py`, call
`run_comprehensive_tests()`, then write the timestamped
`round_trip_report_*.md` here via the report mixin's
`generate_report(report, output_file)` (JSON export shape in
`round_trip_results.py`). Archived timestamped files are historical
samples kept for manual regression inspection — they are not CI gates and
are not regenerated by the test suite.
