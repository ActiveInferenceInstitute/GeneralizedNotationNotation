implementation across GeneralizedNotationNotation and fep_lean. Existing

## GNN behavior

Run identity now binds source, configuration, and artifacts through sessions,
resume, reproduction, manifests, and container plans. Container composition
preserves reviewed security settings and rejects unsafe path aliases. Public
continuous dispatch reaches five supported backends before categorical-table
validation; a nonstationary three-step JAX regression exercises transitions and
absolute output routing. OpenAI synchronous wrappers handle an active event loop
without retrying a provider RuntimeError.

Deserialization uses hardened XML handling and restricted pickle/classifier
loading, including cached extension opcodes and trailing-payload rejection.
Typing, optional-dependency behavior, tests, and maintained terminology were
reconciled. Concurrent GEO additions and rectangular POMDP support were preserved.

The shared immutable receipt engine replaces duplicated verifier behavior with
checked-byte generation, explicit canonical render provenance, versioned source
custody, recursive imports, resolved toolchain identity, and strict native
transcript/axiom validation. The full-run owner manifest is version 14 and
includes all five new verification modules. Persistence tests close SQLite
connections deterministically.

Q5 has six current native theorem reports, Q6 has five, and Q7 has twelve.
All three schema-2 receipts validate; every report uses only standard axioms.
Q6 covers raw embedded Julia input tables. Q7 bounds decoded scalar-OU
coefficients and real-arithmetic prediction errors; it does not prove JAX
floating-point execution or accumulated trajectory error. The shared bridge
contract is version 0.4 in both checkouts.

The existing typed numerical registry now includes independent scalar and Fin4
H2 witnesses while catalogue projections retain their original 15-witness scope.
The Fin4 stationarity test integrates spectral noise independently, so an
incorrect transverse transition rate fails instead of satisfying a tautology.

H2.7 terminal acceptance validates 328 mandatory cases, the explicitly enabled
